## 📋 Phase 2: High-Impact Biases (20 biases)
**Priority**: NEXT - Start here when you resume
**Impact**: Very useful for specific design contexts

### 1. Attentional Bias
**Category**: Perception
**Priority**: Critical for accessibility and focus
**Key Concepts**:
- What grabs user attention
- Visual hierarchy and saliency
- Distraction patterns
**Examples**: Auto-playing videos, animated CTAs, notification badges

### 2. Change Blindness
**Category**: Perception
**Priority**: Critical for updating UI
**Key Concepts**:
- Users miss changes that aren't highlighted
- Need for visual feedback
- Transition animations
**Examples**: Cart updates without feedback, silent form errors

### 3. Context Effect
**Category**: Perception
**Priority**: High for product displays
**Key Concepts**:
- Surrounding items affect perception
- Product comparison strategies
- Decoy pricing
**Examples**: Good-Better-Best pricing tiers

### 4. Priming
**Category**: Perception
**Priority**: Critical for onboarding
**Key Concepts**:
- Early exposure influences later decisions
- Visual and textual priming
- Expectation setting
**Examples**: Security badges before payment, trust signals

### 5. Picture Superiority Effect
**Category**: Memory
**Priority**: Critical for content design
**Key Concepts**:
- Images remembered better than text
- Icon vs text labels
- Visual storytelling
**Examples**: Icon navigation, infographics, product photos

### 6. Processing Difficulty Effect
**Category**: Perception
**Priority**: High for readability
**Key Concepts**:
- Harder to read = less trusted
- Font legibility matters
- Cognitive load reduction
**Examples**: Clean typography, clear hierarchy, readable fonts

### 7. Salience Bias
**Category**: Perception
**Priority**: Critical for CTAs
**Key Concepts**:
- Most noticeable = most important (perceived)
- Color, size, motion attract attention
- Visual weight hierarchy
**Examples**: Bright CTA buttons, notification dots, animated elements

### 8. Selective Perception
**Category**: Perception
**Priority**: High for content strategy
**Key Concepts**:
- Users see what they expect/want to see
- Confirmation seeking behavior
- Mental models
**Examples**: Skimming patterns, F-pattern reading

### 9. Spacing Effect
**Category**: Memory
**Priority**: Medium for learning interfaces
**Key Concepts**:
- Spaced repetition improves retention
- Onboarding timing
- Tutorial pacing
**Examples**: Progressive disclosure, multi-step tutorials

### 10. Illusory Truth Effect
**Category**: Memory
**Priority**: High for marketing
**Key Concepts**:
- Repeated information feels more true
- Message repetition strategy
- Brand consistency
**Examples**: Repeated value propositions, testimonial placement

### 11. Reciprocity Norm
**Category**: Social
**Priority**: Critical for conversion
**Key Concepts**:
- Give before you ask
- Free trials and samples
- Value-first approach
**Examples**: Free tier, trials, downloadable resources

### 12. Authority Bias
**Category**: Social
**Priority**: Critical for trust
**Key Concepts**:
- Trust experts and authorities
- Credentials and certifications
- Industry recognition
**Examples**: "As seen on", expert endorsements, security badges

### 13. In-Group Bias
**Category**: Social
**Priority**: High for community features
**Key Concepts**:
- Favor your own group
- Community building
- Exclusive access
**Examples**: Member-only content, VIP tiers, community badges

### 14. Conformity
**Category**: Social
**Priority**: Critical for social features
**Key Concepts**:
- Following the crowd
- Default choices matter
- Peer pressure patterns
**Examples**: "Most popular" tags, default selections

### 15. Commitment Bias
**Category**: Decision-Making
**Priority**: High for engagement
**Key Concepts**:
- Stick with initial choices
- Progressive commitment
- Sunk cost prevention
**Examples**: Onboarding checklists, progress tracking

### 16. Cognitive Dissonance
**Category**: Social
**Priority**: Medium for post-purchase
**Key Concepts**:
- Reduce conflicting beliefs
- Post-purchase validation
- Justification mechanisms
**Examples**: Order confirmations with benefits, purchase validation

### 17. Dunning–Kruger Effect
**Category**: Social
**Priority**: Medium for skill-based products
**Key Concepts**:
- Beginners overestimate abilities
- Gradual difficulty curves
- Skill feedback
**Examples**: Tutorial difficulty, progressive challenges

### 18. False Consensus Effect
**Category**: Social
**Priority**: Medium for personalization
**Key Concepts**:
- Assuming others agree with you
- Personalization importance
- Diverse representation
**Examples**: Recommendation diversity, varied testimonials

### 19. Fundamental Attribution Error
**Category**: Attribution
**Priority**: Medium for error messaging
**Key Concepts**:
- Blame people, not circumstances
- Error message empathy
- System vs user fault
**Examples**: "Something went wrong" vs "You did X wrong"

### 20. Self-Serving Bias
**Category**: Attribution
**Priority**: Medium for gamification
**Key Concepts**:
- Take credit for success, blame others for failure
- Achievement framing
- Positive reinforcement
**Examples**: "You earned a badge" vs "Badge unlocked"

For each bias (use existing biases as templates):

1. **Create directory**: `mkdir src/biases/[bias-name]`
2. **Create index.ts**: Copy from `anchoring-bias/index.ts` as template
3. **Fill all 11 sections**:
   - Metadata (id, name, category, tags)
   - Definition (simple, detailed, psychology basis)
   - Design Impact (when to use, avoid, mistakes, impact areas)
   - Examples (good, bad, real-world, A/B tests)
   - Detection (visual cues, patterns, questions)
   - Intent (AI system prompt + output schema) ⚠️ CRITICAL
   - Guidelines (implementation, dos/donts, best practices)
   - Resources (papers, books, articles, videos)
   - Relationships (complements, conflicts, confused with)

4. **Export from index.ts**:
   ```typescript
   // src/biases/index.ts
   export { attentionalBias } from './attentional-bias/index.js';
   ```

5. **Add to registry**:
   ```typescript
   // src/biases/index.ts
   export const biasRegistry = {
     // ... existing
     'attentional-bias': attentionalBias,
   }
   ```

6. **Update BIAS_INDEX.md**: Mark as complete ✅

7. **Build and test**:
   ```bash
   pnpm build
   # Test at http://127.0.0.1:5173/packages/design-advisor/test.html
   ```
