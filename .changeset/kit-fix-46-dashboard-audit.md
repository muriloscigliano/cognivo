Library-level findings of the growth-kit dashboard design audit (2026-11-17), each with a test (token values in `node --test`, behaviour and computed styles in real Chromium).

- **One control scale (tokens).** Buttons and inputs are `sm` 32 / `md` 36 / `lg` 40 px (were 32 / 48 / 56), radius 8 px at every size (`--cg-component-button-radius-*`, `--cg-component-input-radius`); `cg-select` follows the input. `--cg-size-touch-target` (44 px) is the phone target size.
- **Dark surface ladder (tokens, both presets).** `--cg-color-surface-canvas-background` < `-panel-background` < the new `-raised-background`, lighter as it rises in dark (`#0b0b0c` / `#141416` / `#1b1b1e`), plus `--cg-color-surface-hairline` (white 8 %) and `--cg-color-surface-hover` (white 6 %). Light: grey-100 canvas, white panel, grey-50 raised, grey-200 hairline. Text, muted text and links on the raised step and muted text on the panel are in the contrast gate.
- **Quieter tints and dialogs (tokens).** Badge backgrounds are about 8 % of their hue (dark 10 %), with a new neutral tint (`--cg-color-badge-background-neutral`, `--cg-color-badge-text-neutral`); the dialog backdrop is black at 32 % (dark 56 %); `--cg-component-modal-radius` is 12 px.
- **Sizes (tokens).** `--cg-component-badge-height` 28 px; `--cg-component-segmented-control-height-md` 32 px with a 2 px padding (26 px options, 3 px inset with the border); `--cg-component-pagination-button-size` 28 px; table densities `--cg-component-table-row-height-list` (60 px) / `-data` (40 px), `--cg-component-table-header-height` (36 px) and `--cg-component-table-fade-size`; `--cg-component-input-label-gap` (6 px).
- **Fields: label on top, errors in place.** `cg-input` and `cg-textarea` draw their `label` above the field by default (12 px / 500, muted, 6 px gap; a `<label for>` that names and focuses the field); `label-position="floating"` keeps the floating label (it now fits the 36 / 40 px heights). `cg-select`'s label gap is the same token. When a field fails validation (a form's submit, `checkValidity()`, `reportValidity()`) the browser's bubble is suppressed (`invalid` is cancelled): the field shows the error border, `aria-invalid`, its validation message under it and a `data-invalid` attribute, the first invalid field takes focus, and the message clears once the value is valid (`showInvalid` in `utils/validation`). `cg-textarea` has a `toolbar` slot above the text inside its border (the border and radius moved from the `<textarea>` to a `.frame` around both).
- **Menus.** `cg-select`'s menu is at least as wide as its trigger and 200 px, up to 320 px, and options never wrap; `cg-dropdown` items take `danger: true` (red text; hover stays the neutral fill, also in `cg-context-menu` / `cg-split-button`).
- **Buttons.** `variant="tertiary" type="danger"` is a ghost-danger button (red text, no fill; hover is the neutral overlay). A loading button hides its label with `visibility` (the width stays) and the spinner takes the variant's text colour.
- **`font: inherit` reset.** Native `<button>` / `<input>` / `<select>` / `<textarea>` inside every component inherit the component's font (`hostBase` / `hostBlock`, and `nativeFont` for cg-modal, cg-drawer, cg-dropdown, cg-sidebar, cg-toaster) instead of the browser's 13.33 px control font.
- **Quiet surfaces.** `cg-badge` is one size (28 px full pill, 12 px / 500, ~8 % tint, no border; `size` is accepted and ignored, default `rounded="full"`). `cg-modal`'s backdrop has no blur (black 32 %, dark 56 %), radius 12 px, and its footer buttons are the 36 px default. New `cg-callout quiet` (panel surface, hairline border, the status colour only on a 16 px icon, 14 px title, 13 px muted line) for inline errors. New `cg-empty-state compact` (no icon, start-aligned, 14 px / 500 title, 13 px muted line, the action pill below) for empty cards and lists. New `cg-skeleton variant="row" count="n"`: list rows at the list density with hairlines, one `status` for the group. `cg-segmented-control`: a 32 px track with 26 px options inset 3 px. `cg-pagination`: 28 px grey pills (default `rounded="full"`, sm 24 / lg 36 px), nothing moves on press, and with `page-size` + `total-items` a 13 px muted "1–25 of 90" summary at the left (locale-formatted; message key `range`, pt-BR included).
- **`cg-table` layout.** Two densities: `density="list"` (default, 60 px rows) and `density="data"` (40 px rows at 13 px; `compact` now means data); the header row is 36 px. `variant="flush"`: no outer border, fill or radius (a table inside a card), hairline rows, edge cells aligned to the card padding. `sticky-first` pins the first column (and the selection column) on an opaque fill with the row state painted over it. An overflowing table fades on the edge that has more table behind it (tracks the scroll position; the start fade begins after a pinned column). `stack-below="768"`: below that width each row is a stacked list row — title line, muted 13 px meta line joined with a middle dot, the `stack: 'end'` column at the right, `stack: 'hidden'` columns dropped — with explicit table roles so it stays a table to assistive tech; the read-only `stacked` attribute shows the state. New column option `stack`.
- Form bundle: 13,309 B (gate 13,312, unchanged): paid for by colour-only checkbox states (no press scale or pop), the clear button without its scale-in, transition shorthands, and the loading button hiding its slots instead of five spinner colour rules.

**2.0.0 migration notes (visual):**

- Default control sizes changed: a `cg-button` / `cg-input` / `cg-select` without `size` is 36 px tall (was 48), `size="lg"` 40 px (was 56), and the default corner is 8 px (was 16 / 12). To keep the old scale, set `--cg-component-button-height-md: 48px`, `--cg-component-input-height-md: 48px` and the radius tokens at `:root`.
- Dark theme: the canvas is `#0b0b0c` (was grey-950 `#09090b`) and the panel `#141416` (was grey-900 `#18181b`); the panel border is `--cg-color-surface-hairline`.
- Badge and dialog backdrop colours are lighter; the segmented control's track is 32 px (was 40) and pager buttons 28 px (were 36).
- `cg-input` / `cg-textarea`: a `label` now renders above the field, not inside it. For the old look set `label-position="floating"`. The input has `id="i"` (the textarea `id="t"`) in its shadow root; `helper` text sits 4 px under the field with no side padding. A form's invalid submit no longer shows the browser bubble — fields show their message themselves. The textarea's border, radius and focus ring are on the new `.frame` element.
- `cg-select`: the menu is no longer exactly as wide as the trigger (min 200 px, `max-content`).
- `cg-checkbox`: checking no longer pops / scales the box (the tick still draws in). `cg-input`'s clear button no longer scales in.
- `cg-button` loading: the label is hidden with `visibility: hidden` on its slots, not `color: transparent`.
- `cg-badge`: `size` no longer changes the badge (one 28 px size); the default corner is a full pill and badges have no border. `cg-pagination`: buttons are 28 px grey pills (were 36 px outlined, radius 12); `size="sm"` is 24 px and `"lg"` 36 px. `cg-segmented-control`: options are 26 px in a 32 px track (were 32 in 40).
- `cg-table`: rows are 60 px by default (were about 45 px) and the header 36 px; `compact` rows are 40 px at 13 px (were 12 px type with 6 px padding). Cells have 8 px vertical padding (the row height sets the rhythm). The table's scroll box sits in a new `.scroll-area` wrapper with two `aria-hidden` fade elements. The default `inset` variant's rules now select `[variant="inset"]` (the reflected default), so an empty `variant` attribute no longer gets the inset body.
