Unused shared styles really are dropped, and the library build stays minified. esbuild's syntax minifier folded every `/* @__PURE__ */ (() => css`…`)()` style wrapper into a bare tagged template, which no bundler can drop, so a consumer's bundle of `cg-input` kept every keyframe in `motion.css` (shimmer, fadeSlideIn, pulse, scaleIn, …). The 47 shared style exports are now `/* @__PURE__ */ pureStyle(() => css`…`)` — a call to a named function, which the minifier keeps and bundlers drop when unused. A test checks that every style in the built chunk is still a pure call, that the ES and CDN (`cognivo.min.js`) builds are minified. The size test's old sentinel for the leak (`cg-ai-effect-glow`) was dead — no component uses that style — so the sentinels are now styles some component does use, each proven live by bundling that component. The test also has a lower bound (9 KB) and checks the three components' code is present. Measured input + checkbox + button + Lit: 12,986 B gzip (12.68 KB); gate 13 KB.
