The primary fill is a theme decision, and selection can be neutral: a documented **neutral theme preset** (design direction: black primary pill, no accent in hover, focus or selection).

**Opt in:** load `@cognivo/tokens/themes/neutral.css` after `@cognivo/tokens`. Without it nothing changes in the resting look: the primary stays the brand lime and selected / current states keep their accent.

- **Primary tokens:** `--cg-color-action-primary-background-default` (bg), `-text-default` (fg), `-background-hover` (bg-hover) and `-background-active` (pressed) are the theme tokens every primary fill reads: cg-button, switch on, checkbox / radio checked, slider fill, progress, chip, split button. The neutral preset sets them to gray-950 / white / gray-800 / gray-700 in light and white / gray-950 / gray-200 / gray-300 in dark.
- **cg-button primary** hover and pressed now use its own `-background-hover` / `-background-active` tokens with no overlay on top (secondary, tertiary, danger and status buttons keep the neutral overlay). In the default preset that is the lime's own darker shades, as before the interaction-state change.
- **New selection tokens** (both themes): `--cg-color-selected-background`, `-selected-text`, `-selected-subtle`, `--cg-color-current-indicator`, `-current-text`. Default values are the accent each state used before (primary fill, accent tint, accent text); the neutral preset makes a selected item solid primary and in-range days the opaque `--cg-color-state-selected` grey, with `-state-text` for the current marker (see kit-fix-44). Used by: cg-calendar (selected day, range ends, days in range, today) and so cg-date-picker / cg-date-range-picker; cg-date-time-picker and cg-time-picker (selected day, time options, AM/PM); cg-pagination (current page); cg-steps (current step circle and title); cg-tabs (active label, its count, the underline); cg-toggle outline pressed; cg-navigation-menu open trigger; cg-accordion open bar; cg-collapsible open chevron; cg-combobox / cg-phone-input selected check; cg-thumbnail selected border.
- **Hover and focus are neutral in both presets** (breaking visual change): `--cg-color-input-border-hover` is a grey step (gray-400 / dark gray-600; was the lime primary border), which every field, picker trigger, chip and file drop zone uses; the checkbox and radio hover borders use it too (radio hover fill is the state hover); cg-follow-up, cg-image-block retry, cg-lightbox, cg-overflow-list, cg-thumbnail and cg-steps (clickable) hovers, cg-resizable handle hover / focus, cg-markdown anchor hover, cg-tree-view icon hover, and the keyboard-highlighted cg-combobox option / cg-command item use neutral state tokens instead of lime / green. cg-markdown text selection uses the selection tokens.
- **Contrast gate:** `validate-contrast.mjs` re-evaluates every pair with the neutral preset applied to each theme and gates each pair whose colours the preset changes, through the same baseline keyed by `neutral-light` / `neutral-dark` (see kit-fix-44).
- **Small default-preset differences:** the current step's pulse glow is the selected-subtle tint (a stronger lime tint than before); a button with `status="error"` hides its label while loading, like every other button. *Unchanged here:* `ai-*` components still use the accent in some hover and selected states (the cg-accordion open tint is neutral since kit-fix-44).
- **Size:** input + checkbox + button + Lit was 13,308 B gzip here (gate 13,312; 13,302 B after kit-fix-44): cg-input and cg-checkbox reuse the shared `spin` keyframes, and duplicate declarations were dropped.
