Enter submits forms from every single-line text field, following the HTML rules; `<fieldset disabled>` disables Cognivo fields and buttons.

- **Behaviour change — Enter submits from fields.** Enter in `cg-input`, `cg-password-input`, `cg-number-input`, `cg-phone-input`, `cg-combobox` (when no option is being picked) and `cg-tag-input` (when the draft is empty — Enter with text still adds a tag) now submits the owning form. Before, only `cg-input` did. *Migration:* if a form should not submit on Enter, give it a disabled default button or handle `keydown` and call `preventDefault()` before the field sees it; if you relied on Enter in a password/number/phone field doing nothing, listen for `submit` instead.
- **Behaviour change — implicit submission follows HTML §4.10.21.2** (one shared helper, `src/utils/implicit-submit.ts`). Enter clicks the form's *default button* (the first submit button: `<button>`, `<input type=submit>` or `cg-button type="submit"`), so its click listeners run and a native button becomes `event.submitter`. If that button is disabled, `loading`, or inside a disabled fieldset, nothing is submitted (a later enabled button does not take over). With no submit button, the form submits only when it has at most one text field. *Migration:* forms with two or more text fields and no submit button no longer submit on Enter — add a `cg-button type="submit"`.
- `cg-button` handles clicks on the host, so `cgButton.click()` submits/resets like a click on it.
- Every form-associated component (`cg-button`, `cg-input`, `cg-textarea`, `cg-password-input`, `cg-number-input`, `cg-phone-input`, `cg-checkbox`, `cg-radio`, `cg-switch`, `cg-toggle`, `cg-select`, `cg-combobox`, `cg-tag-input`, `cg-slider`, `cg-rating`, `cg-segmented-control`, `cg-file-input`, `cg-date-range-picker`, `cg-calendar`) implements `formDisabledCallback`: inside a `<fieldset disabled>` its controls are disabled, a submit `cg-button` neither submits on click nor on Enter, and everything comes back when the fieldset is enabled. Fixes `cg-switch` staying disabled after its fieldset was re-enabled (it wrote the fieldset state into its own `disabled` attribute).
