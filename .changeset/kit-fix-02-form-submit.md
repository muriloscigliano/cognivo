Native form submission. `cg-button` is form-associated: `type="submit"` calls `requestSubmit()` on its owning form (constraint validation + `submit` event) and `type="reset"` resets it; `normal`, `danger` and the new `button` type never submit. **Behaviour change — Enter submits:** pressing Enter in `cg-input` submits the owning form, as a native input does (extended to every single-line field, with the HTML default-button rules, in kit-fix-15). *Migration:* a form that must not submit on Enter needs a disabled default button, or a `keydown` listener that calls `preventDefault()`; a `cg-button` that was meant to submit must now say `type="submit"` (the default `normal` never submits). Both call the form methods through `HTMLFormElement.prototype`, so a control named or id'd `submit`/`reset` cannot shadow them. Adds a real-Chromium test harness (`src/__tests__/browser/`, esbuild + Playwright; skips locally when no Chromium is installed, fails in CI — kit-fix-14).
