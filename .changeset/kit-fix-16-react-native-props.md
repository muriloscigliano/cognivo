**Behaviour change — renamed event props.** React's own DOM props (`onClick`, `onChange`, `onInput`, `onSelect`, `onSubmit`, `onReset`, `onLoad`, `onError`, `onCopy`, …) are never used for a Cognivo CustomEvent any more, so they keep their native React meaning on every wrapper. Before, `<CgLink onClick>` received `cg-link-click` instead of the click, and `<CgInput onInput>` received `cg-input` instead of React's input event.

Naming rule (in `scripts/sync-events.mjs`): the event name without its layer prefix (`cg-link-click` → `onLinkClick`), or the full event name when that is still a React prop (`cg-change` → `onCgChange`). A test reads React's prop list from `@types/react` and fails on any collision.
