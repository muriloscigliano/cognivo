Quiet, neutral interaction states from state tokens, in both themes (design direction: "hover and selection is terrible").

**Breaking visual change (2.0.0).** Hover, pressed, selected and focus states are neutral greys everywhere listed below; the lime/green focus ring and accent glows are gone.

- **Tokens (existing greys and overlays only, no new hue):** `--cg-color-state-hover` (black 4% / dark white 6%), `--cg-color-state-pressed` and `--cg-color-state-selected` (black 8% / white 10%), `--cg-color-state-text` (near-black / white), `--cg-color-state-pill-background` + `-pill-border` (white pill with a hairline / dark: the panel colour), `--cg-color-state-focus-border` (near-black / white) and `--cg-color-state-focus-halo` (≈15%), `--cg-color-selection-background` / `-text`, `--cg-transition-duration-state` (150ms) and `--cg-opacity-40`. `--cg-color-focus-ring` is neutral (gray.600 / dark gray.400; was green.700 / lime); `--cg-color-input-border-focus` is the state focus border; the action `*-border-focus` tokens are the focus ring; `--cg-color-surface-sidebar-hover|active|selected-background` are the state hover / pressed / pill. `index.css` now also sets a page-level `::selection` (neutral grey, near-black text), which reaches component text in Chromium.
- **Components:** `cg-sidebar` items (hover fill + near-black text, pressed one step more, the current item a white pill with a hairline that does not change on hover, sub-items text-only, a 2px neutral ring 2px off the item); `cg-table` rows (hover fill, pressed when clickable, checked rows the selected fill, never coloured); `cg-button` (a neutral hover / pressed overlay on every variant's own colour — the primary keeps its colour; disabled is the variant at 40% opacity, `cursor: not-allowed`, no hover; no press scale); `cg-select` (trigger hover/open overlay, near-black focus border + halo, selected option near-black text instead of accent); `cg-segmented-control` (white pill + hairline, near-black text, no press scale, disabled 40%); `cg-link` (hover near-black, never accent, underline fades in instead of growing, no press scale, disabled 40%); `cg-input` (near-black focus border + soft halo instead of the dual ring). Hover rules in these sit under `@media (hover: hover)`; colour transitions are 150ms ease-out.
- **Accent focus and state fills replaced:** every `0 0 0 3px var(--cg-overlay-accent-strong)` focus glow (autocomplete, combobox, date/time/colour pickers, number/password/phone/OTP/tag inputs, textarea, radio, slider, carousel) is the neutral halo; `focusRingSingle` / `focusRingDual` and cg-chip / cg-carousel focus use the neutral tokens; hover / pressed / selected fills in cg-listbox, cg-list, cg-pagination, cg-combobox options, cg-phone-input's trigger, cg-toggle (pressed) and cg-file-input's dropzone are the state tokens.
- **Build:** the CSS-template minifier also drops the space after a declaration's `:` (quoted strings untouched), which keeps the input + checkbox + button bundle inside its 13 KB gate.

*Not changed here (still accent):* selected days in the calendars / date pickers, the active tab, cg-steps, cg-badge and other non-state accents; the primary button's resting colour (still the brand lime — a black primary is a separate decision).
